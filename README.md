# 🎯 ICY - Influencer Outreach Agent (Frontend)

AI-powered influencer marketing platform that turns guesswork into data-driven success.

## 🚀 Features

- **AI-Powered Influencer Discovery** - Find perfect influencers across multiple platforms
- **Brand Fit Analysis** - Advanced scoring for optimal partnerships  
- **Personalized Outreach** - AI-generated messages that drive higher response rates
- **Campaign Management** - Track and manage all your influencer campaigns
- **Performance Analytics** - Comprehensive insights and ROI tracking
- **Real-time Search** - Advanced filtering and search capabilities

## 🛠 Tech Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Charts**: Recharts
- **Icons**: Lucide React
- **HTTP Client**: Axios
- **Routing**: React Router DOM
